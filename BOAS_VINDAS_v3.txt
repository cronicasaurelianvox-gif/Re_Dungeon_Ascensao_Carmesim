1. ABRA O APLICATIVO
   └─ Nenhuma instalação necessária
   └─ Tudo já está pronto

2. VÁ PARA ABA "ITENS"
   └─ Encontre o botão "🎲 Gerar Item"

3. CLIQUE EM "🛠️ GERAR ITEM (MANUAL ASSISTIDO)"
   └─ Nova interface inteligente aparece

4. PREENCHA OS CAMPOS
   └─ Nome: Digite o nome do item
   └─ Tipo: Selecione o tipo
   └─ Qualidade: Escolha a qualidade
   └─ Nível: Digite o nível (sistema valida automaticamente)

5. VISUALIZE O PREVIEW EM TEMPO REAL
   └─ Coluna direita mostra tudo calculado
   └─ Dicas dinâmicas aparecem
   └─ Cores mudam por qualidade

6. CLIQUE "PRÓXIMO"
   └─ Botão ativa quando tudo está pronto
   └─ Modal de item abre com valores calculados

  • Valida que nível está dentro da qualidade
  • Calcula rolls automáticos (1d4 até 10d12)
  • Calcula valor de extras (1 até 6)
  • Garante balanceamento consistente

Qualidades (Atualizadas):
  • Comum: 1-3 níveis
  • Raro: 4-8 níveis
  • Épico: 9-13 níveis
  • Lendário: 14-18 níveis
  • Mítico: 19-22 níveis
  • Celestial: 23-25 níveis

Interface (Redesenhada):
  • Coluna esquerda: Formulário com campos
  • Coluna direita: Preview + Dicas
  • Atualização em tempo real conforme digita

  ✅ Roll:           5d8 (calculado automaticamente)
