⚡ HABILIDADES DINÂMICAS:
═════════════════════════

Sistema de slots baseado em raridade:

├─ Comum/Raro: 0 slots (nenhuma habilidade extra)
├─ Épico/Lendário: 1 slot (1 habilidade especial)
├─ Mítico: 2 slots (2 habilidades especiais)
└─ Celestial: 3 slots (3 habilidades especiais)

Cada slot é:
  • Uma textarea para descrever a habilidade
  • Salva como array com {slot: index, descricao: "..."}
  • Persistente (salva no localStorage)
  • Carrega ao editar item

Fluxo:
  1. Seleciona qualidade → slots aparecem
  2. Preenche cada slot com descrição
  3. Clica Salvar → habilidades salvam
  4. Abre item depois → slots carregam com dados
